## 2) Mission architecture: Autonomous Swarm (role mesh)

### Core agent classes and responsibilities
1. **Research agents**
   - Acquire licensed/public sources and maintain provenance.
   - Produce citation-linked evidence bundles.

2. **Scientific validation agents**
   - Define null hypotheses, controls, and statistical tests.
   - Reproduce findings across independent pipelines.

3. **Geospatial analysis agents**
   - Normalize coordinate systems and geodesic calculations.
   - Generate spatial diagnostics and confidence maps.

4. **Systems modeling agents**
   - Build constrained models tied to established physical baselines.
   - Track assumptions in model cards.

5. **Pattern-recognition agents**
   - Run clustering, anomaly detection, and graph inference.
   - Output candidate signals with calibrated uncertainty.

6. **Historical synthesis agents**
   - Provide chronology-aware context and confound analysis.
   - Prevent cross-era overreach and anachronism.

7. **Resonance simulation agents**
   - Simulate acoustic/field behavior with declared parameters.
   - Quantify sensitivity and error bounds.

8. **Ethical governance agents**
   - Enforce claims taxonomy and publication safeguards.
   - Flag ambiguity, overclaiming, and misinformation risk.

9. **Visualization agents**
   - Generate evidence-first dashboards and uncertainty overlays.
   - Display data lineage, model version, and confidence tiers.

10. **Strategic forecasting agents**
    - Prioritize experiments by expected information gain.
    - Produce risk-weighted roadmap scenarios.

## Phase 2.5 — “Find the 12” Candidate Activation Protocol

### Definition
“The 12” = top 12 candidates by reproducible multi-signal score.

### Scoring
`Score(c) = w1*Alignment + w2*Geomag + w3*Acoustic + w4*Astronomy + w5*Fractal + w6*TemporalCoherence`

Requirements:
- pre-registered weights,
- perturbation sensitivity analysis,
- bootstrap confidence intervals.

### Activation (strict meaning)
A candidate is “activated” only when it moves from **Exploratory** to **Validated Testing Queue** and passes all gates:
1. survives null-model + multiple-comparison correction,
2. replicates in at least two independent pipelines,
3. exceeds pre-registered minimum effect size,
4. has a scheduled falsification test.

### Output card (required)
- candidate id + coordinates,
- sub-scores and confidence interval,
- confounds,
- falsification protocol,
- status (Exploratory / Validation / Replicated / Rejected).
