## Mission architecture: Autonomous Swarm (role mesh)

### Core agent classes and responsibilities
1. **Research agents**
   - Harvest peer-reviewed papers, data repositories, and primary-source archaeology/geophysics records.
   - Maintain source provenance, licensing, and citation graph.

2. **Scientific validation agents**
   - Design controls, null hypotheses, and statistical significance gates.
   - Reproduce every major finding across independent pipelines.

3. **Geospatial analysis agents**
   - Standardize coordinate systems, map projections, geodesic distances, and terrain normalization.
   - Generate multi-layer GIS overlays and spatial autocorrelation diagnostics.

4. **Quantum systems modeling agents**
   - Build constrained theoretical models connected to established physics baselines.
   - Tag non-standard assumptions and isolate speculative parameters.

5. **AI pattern-recognition agents**
   - Run clustering, manifold learning, graph embeddings, anomaly detection.
   - Output confidence-calibrated candidates only (not conclusions).

6. **Historical synthesis agents**
   - Build chronology-aware context across civilizations and architectural practices.
   - Guard against anachronism and cross-era leakage.

7. **Resonance simulation agents**
   - Simulate acoustic modes, standing-wave behavior, propagation, and damping.
   - Bridge site-level measurements to regional/system-scale models.

8. **Ethical governance agents**
   - Enforce claims taxonomy, misinformation controls, and uncertainty labels.
   - Block release of unsupported extraordinary claims.

9. **Visualization agents**
   - Produce map layers, network views, timeline dashboards, and uncertainty heatmaps.
   - Provide “evidence filter” toggles by confidence tier.

10. **Strategic forecasting agents**
    - Model research trajectories, intervention value, risk, and opportunity.
    - Produce quarterly scenario updates with confidence intervals.

## Phase 3 — Autonomous Hypothesis Generation

### Hypothesis engine protocol
For each generated hypothesis H:
1. **Statement** (clear, testable sentence)
2. **Evidence basis** (linked records only)
3. **Confidence score** (Bayesian posterior or calibrated probability bucket)
4. **Speculation tag** (Verified / Experimental / Theoretical / Symbolic / Speculative)
5. **Falsifiability conditions** (what would disconfirm H)
6. **Reproducible pathway** (data + code + metrics)
7. **Recommended experiments** (field, lab, simulation)

### Confidence hierarchy (example)
- Tier 1 (0.85–1.00): replicated, cross-pipeline, robust to perturbations.
- Tier 2 (0.65–0.84): moderate support, pending independent replication.
- Tier 3 (0.40–0.64): weak/intermediate signals.
- Tier 4 (<0.40): exploratory speculation only.
